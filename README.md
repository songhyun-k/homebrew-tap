# Homebrew tap

Native macOS tools by [songhyun-k](https://github.com/songhyun-k).

```sh
brew install songhyun-k/tap/muse
muse
```

[muse](https://github.com/songhyun-k/muse) brings Apple Music to your terminal.
Requires macOS 14+ on Apple Silicon. No extra language runtime is needed.

To update:

```sh
brew update
brew upgrade songhyun-k/tap/muse
```

Formulae pin a versioned release and SHA-256. Updates preserve your playlists and settings.
